# E-Commerce Customer Behavior & Purchase Pattern Analysis

## Description
This project analyzes an e-commerce customer dataset to uncover purchasing behaviors, engagement across digital channels (app vs. website), and the primary drivers of yearly customer spending. It features an exploratory data analysis Jupyter notebook (`ecommerce_eda.ipynb`) and an interactive Streamlit dashboard (`app.py`).

## 3 Key Findings
1. **Primary Spending Driver:** Length of Membership has the strongest positive correlation with yearly spending, proving that long-term customer retention is vital.
2. **App vs Website Engagement:** Customers who spend more time using the mobile app show higher yearly spending compared to those relying solely on the website.
3. **Strategic Recommendation:** The business should focus loyalty rewards and promotional incentives on users approaching their second or third year of membership to maximize customer lifetime value.
